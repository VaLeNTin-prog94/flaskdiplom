Веб приложение предназначенное для управления постами о выпечках. 

## Содержание
Оно предлагает интуитивно понятный интерфейс для создания, редактирования, удаления и обновления записей 
Form для обработки форм и добавления записей в базу данных
Пользовательские функции регистрации и входа в систему

## Использование
Flask — это легковесный веб-фреймворк для языка Python, который предоставляет минимальный набор инструментов для создания веб-приложений. На нём можно сделать и лендинг, и многостраничный сайт с кучей плагинов и сервисов. Не фреймворк, а мечта!

## Выводы создания приложения на Flask


1. Легкость в использовании: Flask очень прост в освоении, что позволяет быстро начать разработку приложения. Даже новички могут быстро разобраться в его основах.

2. Гибкость: Flask не навязывает разработчику никаких определенных решений, поэтому вы можете настраивать свое приложение по своему усмотрению и использовать только те компоненты, которые вам нужны.

3. Легкость подключения расширений: В Flask просто добавлять дополнительные функции, такие как работа с базами данных или аутентификация пользователей. Это экономит время и усилия.

4. Отличная документация: Документация Flask ясная и полная, что помогает быстро находить нужную информацию и учиться на собственных ошибках.

5. Неплохая производительность: Хотя Flask не самый быстрый фреймворк, его простота и небольшие размеры делают его достаточно эффективным для большинства небольших и средних приложений.

6. Поддержка сообщества: Сообщество вокруг Flask активно, и вы можете найти множество учебных материалов, примеров и форумов, где можно получить помощь.

В общем, работа с Flask была положительным опытом. Этот фреймворк дает все необходимое для создания простых и эффективных приложений, что делает его любимым выбором для многих разработчиков.
